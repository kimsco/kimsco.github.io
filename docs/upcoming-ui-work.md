# 다음 UI 작업

사용자가 집중 문구 7개 추가와 함께 미리 전달한 후속 작업이다. 이 목록은 구현 완료를 뜻하지 않는다.

- [x] 1.0.137: 스플래시 로고 아래 원형 로딩 스피너 추가. 1.0.138에서 iOS 시작 이미지를 검정으로 바꾸고 웹 로고·로딩 도형 페이드인 적용. 1.0.140에서 원형 스피너를 점 7개의 파도 애니메이션으로 교체.
- [x] 1.0.132: 3대·기록 탭에서 운동 기록 저장 후 화면을 최상단으로 부드럽게 스크롤. 순간이동처럼 위치를 바꾸지 않는다.
- [x] 1.0.132: 3대·기록 탭에서 스크롤하면 화면 상단에 원형 안의 위쪽 화살표 버튼 표시. 누르면 최상단으로 부드럽게 이동.
- [x] 1.0.141: 설정 화면을 큰 제목, 72px 행과 불투명한 둥근 카드로 개편. 프로필 → 알림 → 일반 설정 → 도움말·기타 → 계정 순서이며, 짙은 와인색 배경이 알림 섹션 쪽에서 검정으로 사라진다. 밝은 모드는 옅은 붉은 기운과 흰 카드로 대응한다.
