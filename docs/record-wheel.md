# 기록 입력 휠 (1.0.99)

- 안정 버전 기준: 1.0.97, 커밋 `a46e1991125f75228172250e2606252b4d79938e`, 로컬 태그 `rollback-baseline-v1.0.97`.
- 3대·보조운동·루틴 알약바의 kg/횟수 입력 6개에 적용한다. 짧은 터치는 기존 키보드 설정과 iOS 포커스 보정으로 연결한다. 450ms 길게 누르면 키보드 없이 휠을 연다. 10px 이상 움직이거나 취소되면 길게 누르기를 취소한다.
- 표시: 하단 시트 대신 입력칸의 실제 폭과 중심에 맞춘 인라인 휠. 선택 행과 위·아래 행 총 3줄을 표시하며 가장자리를 페이드 처리한다. 주변 화면은 어둡게 하지 않고, 원래 입력값은 휠이 열린 동안만 숨긴 뒤 복원한다.
- 휠: 무게 0~500kg, 5kg 간격 / 횟수 1~60회, 1회 간격. 현재 값이 간격에 맞지 않으면 가까운 값을 미리 보여주되 체크 전에는 원본을 바꾸지 않는다. 기존 직접 입력은 그대로 유지한다.
- 체크는 입력칸의 값과 input/change 이벤트만 갱신한다. 서버 쓰기나 기록 저장은 기존 저장 버튼이 담당한다. 취소·배경 탭·Escape는 값을 유지한다.
- 배경 inert와 모달 포커스 순환을 사용한다. 닫을 때는 입력칸 대신 알약바로 포커스를 돌려 키보드 재등장을 피한다.
- 검증: `python tests/record-wheel-smoke.py` (격리 Firebase), `tests/browser_smoke.py`로 기존 저장·타이머 흐름 회귀 검증. 실제 iOS 키보드 표시는 실기기에서 추가 확인한다.
