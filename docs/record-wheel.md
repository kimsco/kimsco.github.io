# 기록 입력 휠 (1.0.109)

- 안정 버전 기준: 1.0.97, 커밋 `a46e1991125f75228172250e2606252b4d79938e`, 로컬 태그 `rollback-baseline-v1.0.97`.
- 3대·보조운동·루틴 알약바의 kg/횟수 입력 6개에 적용한다. 짧은 터치는 기존 키보드 설정과 iOS 포커스 보정으로 연결한다. 200ms 길게 누르면 키보드 없이 휠을 열고, 누른 손가락을 유지한 채 바로 위아래로 돌릴 수 있다. 열리기 전 10px 이상 움직이거나 취소되면 길게 누르기를 취소한다.
- 표시: 하단 시트 대신 입력칸의 실제 폭과 중심에 맞춘 인라인 휠. 선택 행과 위 3개·아래 3개 총 7줄을 표시하며 가장자리를 페이드 처리한다. 주변 화면은 어둡게 하지 않고, 원래 입력값의 글자만 열린 동안 숨겨 최초 터치 대상을 유지한다. 화면 아래 공간에 맞춰 행 높이를 조정한다.
- 휠: 무게 0~500kg, 5kg 간격 / 횟수 1~60회, 1회 간격. 현재 값이 간격에 맞지 않으면 가까운 값을 미리 보여주되 체크 전에는 원본을 바꾸지 않는다. 기존 직접 입력은 그대로 유지한다.
- 체크·취소 버튼은 없다. 다른 곳을 누르거나 Enter를 누르면 선택값과 input/change 이벤트만 갱신하며 닫힌다. 서버 쓰기나 기록 저장은 기존 저장 버튼이 담당한다. Escape 또는 앱 비활성화는 값을 유지하며 닫는다.
- 최초 터치가 이어지는 동안 원래 입력칸의 부모만 inert에서 제외하고, 손을 뗀 뒤 전체 배경 inert를 적용한다. 모달 키보드 포커스는 휠에 유지한다. 닫을 때는 입력칸 대신 알약바로 포커스를 돌려 키보드 재등장을 피한다.
- 검증: `python tests/record-wheel-smoke.py` (격리 Firebase), `tests/browser_smoke.py`로 기존 저장·타이머 흐름 회귀 검증. 실제 iOS 키보드 표시는 실기기에서 추가 확인한다.

숫자는 위에서 아래로 내림차순으로 표시합니다. 큰 숫자는 위쪽, 작은 숫자는 아래쪽이며, 손가락을 아래로 움직이면 값이 커지고 위로 움직이면 작아집니다.

길게 누르기는 200ms로 단축. 행 간격은 공간이 허용하는 범위에서 20% 확대하며, 화면 가장자리에서는 7줄이 들어가도록 제한한다. 중앙의 별도 작은 알약 테두리를 제거하고 입력칸과 조상 배경을 합성한 색을 휠 전체에 적용한다.

1.0.109: 행 간격을 입력 높이의 1.5배(44~66px)로 확대한다. 중앙은 원래 입력칸 위치에 유지하고 하단 공간에 맞춰 간격을 압축하지 않는다. 화면 밖 숫자는 잘리며 위쪽 숫자는 3개까지 표시한다. 다이얼 배경 레이어만 불투명도 50%이며 원래 알약바와 숫자에는 적용하지 않는다.

1.0.109: 숫자 간격은 이전 버전의 절반(22~33px). 선택 행을 따라 움직이는 포커스 테두리를 제거하고 원래 입력칸과 같은 폭·높이의 흰색 테두리를 중앙에 고정한다.

## 원판 다이얼 2안 — 1.0.109
1안 최종 기준은 1.0.104, 태그 `rollback-wheel-v1-v1.0.104`. 105부터 숫자는 입력칸을 지나는 원 둘레를 따라 좌우로 회전한다. 선택값은 원래 입력칸 중심에 고정되며 주변 숫자는 위쪽 곡선을 따라 작아지고 흐려진다. 한 번에 한 입력칸만 펼치고 원판 배경은 50% 불투명도로 표시한다.

1.0.109: 무게 원판은 입력칸 왼쪽에 중심을 두고 3시 방향에서 선택한다. 횟수 원판은 오른쪽에 중심을 두고 9시 방향에서 선택한다. 두 입력칸과 앱 좌우 경계까지의 거리 중 작은 값으로 공통 반지름을 계산해 크기와 중심 거리를 같게 유지하며 좌우 거울 대칭을 적용한다. 보이는 영역은 12시~4시 부채꼴과 그 반사 영역이다.

## 1.0.109 — 1안 복원 및 밀어서 열기
104 태그의 세로 다이얼을 복원한다. 원판 UI를 제거하고 200ms 타이머도 제거한다. 입력칸을 누른 채 수직으로 4px 이상 밀면 즉시 열리고 같은 손가락으로 조절한다. 단순 탭은 기존 키보드 입력을 유지하며 가로 이동은 열기를 취소한다. 104의 고정 테두리·숫자 간격·50% 배경을 유지한다.

1.0.109: 다이얼을 연 동안 빈 입력칸의 kg/회 placeholder도 숨긴다. 숫자 탭은 해당 값으로 이동하지 않고 현재 중앙 선택값을 적용하며 닫는다. 스크롤 뒤 발생한 클릭은 닫기로 취급하지 않는다.

1.0.109: 다이얼을 닫은 뒤 포커스를 받는 비대화형 입력바 컨테이너의 기본 outline을 숨긴다. 입력 필드로 다시 포커스하지 않으므로 키보드 재등장을 방지하는 기존 동작은 유지한다.
