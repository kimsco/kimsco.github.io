이용약관

MuscleFlow는 개인의 운동 및 식단 기록을 관리하는 PWA 서비스입니다. [서비스 이용 조건] - 만 14세 이상만 가입할 수 있습니다 - Google 계정으로 로그인/가입합니다 - 사용자가 입력한 데이터는 Google Firestore에 저장됩니다 - 오프라인 상태에서도 로컬 저장소에 임시 저장됩니다 [사용자의 책임] - 자신의 계정 보안 유지 - 타인의 계정 무단 사용 금지 - 불법 또는 부정적 목적의 사용 금지 - 타인의 개인정보 입력 금지 [서비스 변경 및 중단] - 운영자는 사전 공지 후 서비스를 변경하거나 중단할 수 있습니다 - 중단 시 사용자 데이터는 30일 내에 삭제됩니다

개인정보처리방침

[수집하는 정보] - 이메일 (Google에서 제공) - 사용자 ID (Firebase가 생성) - 운동 기록 (사용자가 직접 입력: 운동명, 무게, 반복, 세트, 날짜) - 식단 기록 (사용자가 직접 입력: 음식명, 단백질, 탄수화물, 지방, 날짜) [정보 저장 위치] - Google Firestore (클라우드 데이터베이스) - 로컬 저장소 (브라우저 로컬스토리지) - 데이터는 Google 데이터센터에 저장됩니다 [정보 사용 목적] - 운동/식단 기록 저장 및 조회 - AI 챗봇 질문 응답 (질문만 전송, 개인정보 미포함) - 통계 및 차트 데이터 생성 - 서비스 오류 분석 및 개선 [정보 보호] - Firebase Security Rules로 사용자 본인의 데이터만 접근 가능 - 다른 사용자의 데이터 접근 불가능 [정보 삭제] - 회원 탈퇴 시 모든 Firestore 데이터는 즉시 삭제됩니다 - 로컬 저장소 데이터도 함께 삭제됩니다 - 삭제된 데이터는 복구되지 않습니다 [제3자 제공] - Google Firestore (데이터 저장, 필수) - Cloudflare Workers (AI 챗봇 프록시) - 그 외 제3자에 제공하지 않습니다
